How the work was done

  • Instructions as the source of truth. AGENTS.md holds the rules, file map, and checklist that every agent session reads first.
  • Rules stay testable. The game engine, solver, seeds, and stats are plain modules with Node tests; the page only draws and handles input.
  • Check before claiming. Each change was run through the tests and checked in a real browser on desktop and phone sizes.
  • Screenshots before visual changes. A baseline is saved first, so every change can be compared.
